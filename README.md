# Inventario-De-Coletas
Sistema web de inventário de coletas. O auditor escolhe seu nome e o embarcador, e bipa os códigos, que são validados (só letras e números) e checados contra duplicidade, com limite de 2.500 peças. Permite consultar a lista e exportar tudo em Excel ou PDF, reiniciando a auditoria. Dados salvos no navegador, visual Windows XP.
